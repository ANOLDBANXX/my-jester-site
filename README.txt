# JESTER

JESTER is a frontend prototype combining social-network features inspired by Instagram and WhatsApp.

## Files
- index.html — application structure
- style.css — responsive JESTER design
- app.js — interactions and demo functionality
- config.js — backend configuration placeholders

## Run locally
1. Keep all four files in the same folder.
2. Open index.html in a browser.
3. For a real online app, connect Supabase and add authentication, database tables, storage, realtime messaging and security rules.

## Suggested Supabase tables
profiles
posts
comments
likes
followers
stories
story_views
conversations
conversation_members
messages
notifications
contacts
reels

Never place a Supabase service-role key in frontend files.
